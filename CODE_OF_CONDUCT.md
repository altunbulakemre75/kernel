# Code of conduct

Kyvern follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, and keep discussions about the
work, not the person.

If someone's behaviour in this project is unacceptable, open an issue titled
"Code of conduct report" without any details or names, and the maintainer
(@altunbulakemre75) will arrange a private channel with you. For content in an
issue, pull request or discussion you can also use GitHub's **Report content**
option, which goes to GitHub.

The maintainer will review every report and decide on a response, from a
private warning to removing comments or banning someone from the project, as
the Contributor Covenant's enforcement guidelines describe.
